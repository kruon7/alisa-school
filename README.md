# ALISA SCHOOL

**ALISA SCHOOL** — интерактивная образовательная платформа для школьников 5–11 классов.
Это единый учебный помощник: теория по школьным предметам, тесты, задачки, калькуляторы и встроенный **AI-ассистент на базе Google Gemini** — всё в одном месте, бесплатно и без установки.

---

## Что это за сайт

Современное веб-приложение, где школьник может:

- изучать темы по 11+ предметам с подробными объяснениями и примерами;
- проходить **тесты с похвалой, разбором ошибок и рекомендациями**;
- решать **задачки** трёх уровней сложности с проверкой и решением;
- пользоваться **калькулятором**: обычный, дроби, умножение/деление столбиком, дискриминант;
- применять «школьные» инструменты: факты по предметам, тренажёр таблицы умножения, перевод систем счисления, конвертер единиц, счётчик слов, шпаргалки, таймер и заметки;
- задавать любой вопрос **AI-ассистенту Максику** или просить объяснить непонятную тему — он отвечает прямо на сайте.

## Как сайт помогает людям

- **Заменяет дорогого репетитора для простых вопросов.** Если ученик что-то не понял на уроке — AI-ассистент объяснит тему простым языком с примерами и аналогиями, в любое время.
- **Снимает стресс от ошибок.** Тесты хвалят за верные ответы, мягко разбирают ошибки и подсказывают, что повторить.
- **Экономит время родителей и учителей.** Материалы собраны в одном месте: не нужно искать по десяткам сайтов.
- **Готовит к экзаменам.** Есть разделы ОГЭ и ЕГЭ с занятиями и пробниками.
- **Развивает самостоятельность.** Ученик сам выбирает предмет, тему и уровень — подстраивается под его темп.
- **Доступно всем.** Работает в любом браузере, бесплатно, без регистрации.

### AI-ассистент «Максик»

- Плавающая кнопка-робот с уведомлением «пришло сообщение» — заметна на любой странице.
- Отвечает на вопросы по предмету и теме, которые ученик сейчас изучает.
- Генерирует развёрнутые объяснения с формулами, примерами и аналогиями.
- При открытии здоровается и предлагает быстрые вопросы-подсказки.

## Технологии

- **Фронтенд:** HTML + CSS + JavaScript (vanilla, без библиотек) — один файл `js/Алиса School .html`.
- **Бэкенд:** Python + FastAPI, раздаёт сайт и проксирует запросы к AI.
- **AI:** Google Gemini (SDK `google-genai`) — отвечает на русском языке, поясняет темы, генерирует задачи.
- **Хранилище:** `localStorage` — прогресс, настройки, заметки и темы сохраняются в браузере без регистрации.

## Эндпоинты API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/` | Раздаёт сайт |
| GET | `/api/health` | Проверка работы и статуса ключа AI |
| POST | `/api/explain` | ИИ-объяснение темы `{grade, subject, topic}` |
| POST | `/api/ask` | Ответ AI-ассистента `{grade, subject, question, topic}` |
| POST | `/api/task` | Генерация задачи `{subject, level}` |

## Как запустить

1. Скопируйте ключ Gemini API: https://aistudio.google.com/apikey
2. Впишите его в `site/backend/.env` (см. `backend/.env.example`)
3. Запустите сервер бэкенда (подробнее: `backend/README.md`):

```bash
cd site/backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --host 127.0.0.1 --port 8000
```

4. Откройте в браузере **http://127.0.0.1:8000** — сайт загрузится вместе с AI-функциями.
